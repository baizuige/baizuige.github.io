工具

GitLens — Git supercharged

在源代码管理中查看 COOMITS、BRANCH、TAGS 等 GIT 仓库信息，行内显示提交缩略信息

CodeSnap

代码截图美化工具，选中代码后，右键选择 CodeSnap 即可打开 CodeSnap窗口，Ctrl + c 保存截图

Project Manager

会在侧边栏添加 Project Manger 栏，可在其中添加当前仓库，方便进行多仓库管理（当前窗口打开或新窗口打开）

前端开发

Vue - Official

提供 Vue 项目的代码高亮

ESLint

Prettier - Code formatter

Error Lens

行内显示报错信息

Auto Rename Tag

虽然 VS Code 内部做了支持但默认不开启，需要在设置中搜索 Linked Editing 手动开启，此外 jsx 中不支持，为了方便推荐安装。

Turbo Console Log

  • 添加日志 Ctrl + Alt + L
  • 注释所有插件添加的日志 Shift + Alt + C
  • 取消注释所有插件添加的日志 Shift + Alt + U
  • 删除所有插件添加的日志 Shift + Alt + D
